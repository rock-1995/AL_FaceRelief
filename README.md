# AmanatsuLocation Face Relief Mods

Requires AmanatsuLocation, BepInEx 6 IL2CPP, and AL Sideloader. Download a ZIPMOD from
[Releases](https://github.com/rock-1995/AL_FaceRelief/releases), put it in the game's
`mods` folder, and restart. Select a variant under face outlines in the character creator.

- **Face Relief** adds twelve shading variants across the two original face outlines.
- **Face Normal Relief** provides the same twelve choices with tangent-space normal maps.
